# Tidepopper 📚

App de estudio personal que reúne cuatro herramientas en una:

| Módulo | Qué hace |
|---|---|
| 🃏 **Flashcards** | Pegas tus notas y la app genera preguntas de repaso. Repetición espaciada para recordarlas a largo plazo. |
| 💡 **Concepto del día** | Cada día una palabra o concepto del idioma o tema que estás aprendiendo. |
| 📖 **Biblioteca** | Registro de libros, series y películas con notas y citas favoritas. |
| 🎯 **Objetivos** | "Quiero aprender X": mini objetivos semanales y seguimiento del progreso. |
