# Visión y decisiones abiertas

## Idea central
Un solo lugar para aprender: lo que lees y estudias (Biblioteca, notas) alimenta
las Flashcards y el Concepto del día, y todo suma a tus Objetivos.

## Decisiones pendientes
- [ ] Plataforma: ¿móvil, web, o web instalable (PWA)?
- [ ] ¿Uso personal o con cuentas para otras personas?
- [ ] ¿Funciona sin conexión?
- [ ] Generación de flashcards: ¿con IA (Claude API) o manual al principio?
- [ ] Algoritmo de repaso: ¿SM-2 (tipo Anki) o algo más simple?
- [ ] ¿Qué módulo se construye primero (MVP)?

## Ideas sueltas
- Racha diaria de estudio que combine todos los módulos.
- Crear flashcards directamente desde una cita guardada en la Biblioteca.
- Resumen semanal: tarjetas repasadas, objetivos cumplidos, libros avanzados.
